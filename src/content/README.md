# Content workflow

Long-form website copy lives here, separated by language.

- `en/` contains the approved English website content.
- `fr/` contains the approved French website content.
- `shared/` contains non-language-specific structured data such as image keys, office coordinates, project image paths, certifications and repeated company facts.
- `contentStatus.js` tracks sections where one language is still missing or pending approval.

Keep short UI labels such as navigation, buttons and accessibility text in `src/i18n/locales`.
